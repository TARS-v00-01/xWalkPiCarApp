# Contributing to xWalk applications

Organization membership requests and approval automation are hosted in the dedicated
[TARS-v00-01/.github repository](https://github.com/TARS-v00-01/.github).

[Request organization membership](https://github.com/TARS-v00-01/.github/issues/new?template=membership-request.yml)
and read the [organization contribution guide](https://github.com/TARS-v00-01/.github/blob/master/CONTRIBUTING.md).
An organization owner approves the request; after accepting the invitation, the requester becomes a regular member
with the organization's existing Read access to all private repositories. This is organization membership,
not access limited to this application repository.

Report public application bugs using the [bug form](https://github.com/TARS-v00-01/xWalkPiCarApp/issues/new?template=bug-report.yml).
Keep private implementation details in the owning private module. Propose fixes through a fork and pull request
in the repository that owns the changed files. Maintainers import accepted proposals into Gerrit for review,
CI, and submission before GitHub publication. See the [Git guide](GIT_GUIDE.md) for direct Gerrit contribution.
